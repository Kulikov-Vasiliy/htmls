# htmls
## О проекте
Проект создан в целях ознакомления с основами создания django-приложений в рамках домашних заданий во время обучения.
## Инструкции
По установке:
  * Для PyCharm:
    1. клонировать репозиторий, введя в терминале git clone https://github.com/Kulikov-Vasiliy/htmls
    2. установить зависимости через активированное виртуальное окружение: poetry install
  * Для GitHub:
    1. на странице проекта на кнопке <> Code открыть выпадающий список
    2. выбрать download zip или клонировать через ссылку https или ssh
По применению проекта:
1. открыть модуль main через pycharm (реализовано открытие только страницы "контакты")
2. запустить виртуальное окружение, например для win venv\Scripts\activate, затем python manage.py runserver
3. запустить run в main/manage:
   - применить комбинацию "пробега" (для ее поиска: настройки->keymap...-> 4 configure keymap -> в лево списке настроек должно быть keymap в правом/центральном перечне развернуть папку tool <ваша ос>(например tool windows))
   - сверху окна pycharm, кнопку run(обычно изображается как кнопка "play")
## Дополнительно
* В пакетах src и tests на данный момент пусто
* В config расположены основные пакеты для работы django:
- settings: INSTALLED_APPS - хранит приложения
- urls: urlpatterns - хранит ссылки на url приложений (* !! не путать с url разрабатываемых страничек в приложении *)
* В catalog лежит текущий проект - сам пакет является приложением, в составе которого:
- templates - директория, в которой лежат html-файлы (странички, сверстанные в рамках дз)
- static - директория с пользовательскими стилями (пока что без разделения на css и js)
- основные файлы проекта:
1. контроллеры (views)
2. ссылки на странички (urls)
3. остальные модули пока не задействованы
* При пробеге проекта, в консоль подается ссылка на проект (url-адрес приложения) и лог изменений в процессе использования приложения
